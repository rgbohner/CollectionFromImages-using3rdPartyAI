# File guide

Headers identify the project owner, with Codex assistance for the standalone adaptation. Dates record when these headers were documented, not the original creation dates of adapted code. `package-lock.json` is generated by npm; its dependency authors and licenses are not replaced by this project attribution.

Source and supporting text files have comment headers in place. JSON does not support comments, the image is binary, the lockfile is generated, and LICENSE retains the standard MIT text; their entries here provide the same information without changing those formats. Generated outputs, local `.env`, dependencies and Git internals are outside the tracked project files.
